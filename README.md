# QSPR Modeling for Herbicide Bioactivity (CHM488)

## Project Overview
This project applies Quantitative Structure–Property Relationship (QSPR) modeling to analyze and predict herbicide bioactivity using computational chemistry and data analysis techniques.

## Objectives
- Analyze herbicide molecular descriptors
- Explore relationships between chemical structure and bioactivity
- Build predictive models for herbicide effectiveness
- Interpret computational results for chemical insights

## Files Included
- `CHM488 Final Project Report.docx` – Final written report
- `CHM488 Final Project_...` – Project notebook/script
- `herbicides_descriptors.csv` – Molecular descriptor dataset
- `herbicides_raw.csv` – Raw herbicide dataset

## Methods Used
- Data preprocessing
- Descriptor analysis
- QSPR modeling
- Statistical/computational evaluation
